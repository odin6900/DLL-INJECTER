## 🛠️ Getting Started

### Prerequisites

<ul>
	<li>Windows 10/11</li>
	<li>.NET Framework 4.8 or higher</li>
	<li>Visual Studio 2019/2022 (recommended)</li>
</ul>

### Installation

1. <b>Clone</b> or <b>download</b> this repository.
2. Open <code>INJECTER.sln</code> in Visual Studio.
3. Restore NuGet packages if prompted.
4. Build and <b>Run</b> the solution.

### Usage

1. Launch the application.
2. Select a target process from the list.
3. Choose a DLL to inject.
4. Click the <b>Inject</b> button.
